# Technical skill icons

These assets are stored locally and identify the tools in the technical toolkit.
Each icon is paired with its visible skill name. ROS1 and ROS2 share the ROS
brand mark; their text labels distinguish the versions.

| Icons | Source |
| --- | --- |
| C++, Python, ROS, Gazebo, Docker, Git, MATLAB | [Devicon original SVGs](https://github.com/devicons/devicon/tree/master/icons) |
| Linux | [Devicon plain Linux SVG](https://github.com/devicons/devicon/blob/master/icons/linux/linux-plain.svg) |
| Nav2 | [Official navigation2 repository](https://github.com/ros-navigation/navigation2/blob/main/doc/nav2_logo.png) |
| MoveIt2 | [MoveIt website icon](https://moveit.ai/assets/icon/apple-icon-180x180.png) |
| MuJoCo | [MuJoCo website icon](https://mujoco.org/frontend/assets/favicon/favicon-32x32.png) |
